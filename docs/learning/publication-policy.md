# GitHub 发布边界

目标仓库：`https://github.com/LAN-boop-666/Cloud-Taste.git`

该仓库当前为公开仓库。课程视频、讲义、产品原型、接口文档、课程成品、最终答案和未明确授权再分发的素材，不应直接上传。

可以公开的内容：

- LAN 跟随课程独立完成和理解后的实现
- 云味餐厅原创品牌与扩展功能
- 自己编写的测试、脚本、说明和学习记录
- 带明确许可证且遵守许可证要求的第三方组件

提交前必须执行：

1. 完整构建和自动化测试
2. 敏感信息检查
3. 第三方资料边界检查
4. `git diff --cached` 人工核对

本地 `docs/prototype`、课程接口文档和 `admin-dist` 主要用于学习联调，不代表可以公开再发布。

这些本地资料目录已加入 `.gitignore`。后端和管理端源码需要按章节显式选择提交文件，禁止直接使用 `git add -A` 上传整个课程骨架。
